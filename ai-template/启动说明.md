# 启动说明

本模板不提供 `start.bat` / `start.ps1`。旧的 PowerShell 启动脚本写死实例路径并按端口杀进程，已从模板移除，不要复制其逻辑。

## 生产环境：systemd

- 后端：`sudo systemctl start|restart|status <后端unit>`，日志 `journalctl -u <后端unit> -n 50`
- Loom：`sudo systemctl start|restart|status <Loom unit>`，配置读 `{AI目录}/.loom/config.yaml`
- 结束进程只按 PID：`kill <PID>`；禁止 `pkill` / `killall` 按名称批量杀

## 通用启动：launcher.py

在项目根目录执行：

```bash
python launcher.py
```

`launcher.py` 读取项目根 `config.yaml`，启动后端；OpenCode 只在 `opencode.enabled: true` 时由它拉起。Loom 不归 `launcher.py` 管理，按上节 systemd 方式单独启动。

后端需要优雅重启时，调用 `POST /api/screen/restart`（Bearer 认证），不要手工杀端口。

## 两种 AI 后端

- Loom（生产推荐）：项目根 `config.yaml` 设 `ai_backend: loom`，配置文件从 `loom-config.example.yaml` 复制为 `{AI目录}/.loom/config.yaml`
- OpenCode（可选）：项目根 `config.yaml` 设 `ai_backend: opencode` 且 `opencode.enabled: true`，`opencode.directory` 指向 `{AI目录}`

## 首次启动

按 `系统初始化指南.md` 完成首次初始化，再启用定时任务。
