# 草稿纸（self/scratch）

> 介于原始数据与长期记忆之间的临时承接层。放那些现在不确定该不该进档案、扔了又可惜的判断、想法、情绪与可疑点。

## 定位

写进来不等于记下来。草稿纸是待整理，不是真值；真值只在 `profile/`、`self/`、`fact/` 与 `topics/` 的正式文件里。

## 谁写

| 写入方 | 时机 | 典型内容 |
|--------|------|----------|
| 主会话 | 聊到值得留但没处放的东西时 | 用户口述的想法、情绪、立场，我的判断，待核线索 |
| 数据检查批次 | 收尾时 | 本批没把握的事实候选、口径疑问、异常线索 |
| 复盘 | 收割时 | 自身跑题或疑问，一般直接收割，无需落草稿 |

## 格式（一行一条，便于机器收割）

```text
- [HH:MM][来源:主会话|批次|复盘][类型:想法|情绪|立场|候选|待核|疑问] 正文
```

- 正文写用户的原话或可核事实，不写我的发挥；推断另起一行标 `[类型:候选]`。
- 不确定的东西标 `[类型:待核]`，并写清怎么核。

## 分片与膨胀

- 按日分片：`self/scratch/{date}.md`；单文件软上限 300 行或 30KB，超了拆成上午与下午两个文件。
- 保留窗口 7 天：已收割的行由复盘标 `→已收割(去向)`，7 天后整行删除；文件清空即删文件。
- 不建索引、不建总表，按日期直接找。

## 与 self/认知.md 的分工

- **草稿纸是未成型的念头**：还说不清判据、没有到期、只有一次观察的东西先落这里。
- **`self/认知.md` 是成型的观察卡**：必须同时有判据、验证方式、到期，缺一条留在草稿纸。
- 已证伪或关闭的卡片由复盘在认知文件中合并或删行，不搬回草稿纸。

## 复盘怎么整理

1. 读当天 `self/scratch/{date}.md`，无文件则跳过。
2. 逐行判 ADD、UPDATE、NOOP 或丢弃。
3. 处理完在行尾追加 `→已收割(目标文件)` 或 `→丢弃(原因)`，不删原文。
4. 不擅自把草稿内容当已确认事实用；候选与待核必须核过才升格。
