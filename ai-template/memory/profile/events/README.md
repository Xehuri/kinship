# profile/events：单次事件记录

> 一次事件一个文件；只记发生过什么，不承载长期结论。

## 写入方

- **复盘**：唯一常规写入方。归属判定为「单次事件，不适合并入 people、事项或属性文件」时新建。
- 主会话可在对话里口述事件，但落盘交复盘；日常聊天不直接写本目录。

## 命名与格式

命名：`{事件}-{date}.md`，正文包含背景、经过、影响、关联人物、关联事项、当日复盘指针。

## 边界

- 长期结论进 `profile/semantic/` 的 people、事项或属性文件；检索行进 `fact/{月}.md`。
- 本目录不建索引、不做总表；文件数应保持很低。事件沉淀为稳定事实后并入 semantic，并在此留指针。
- 事件正文只写证据支持的内容；推断标「待核」。
