2. 复盘每天或每周：新形态须至少 3 天证据才加条；连续 2 次偏离标「待复核」；被推翻的删行，历史去 git。
3. 例外日（放假、调课、生病）不写进规律，只在当天理解文件里标「例外」。
4. 用户口述优先：用户明确说「今天就是这样」，直接改本文件，不用等统计。
