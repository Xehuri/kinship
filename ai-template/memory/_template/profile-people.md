# semantic/people/{人物}.md（人物档案编年史）

> 从 daily 提炼的「关于此人」的浓缩记忆，按时间追加。条目 = 浓缩事件或真值 + 指针指向当日复盘，不复制正文；完结或低频不删，编年史累积。高频人物独立成档，低频泛人物进 `同学朋友.md` 一行一人，证据不足进 `待确认人物.md`。

## 身份与稳定真值

- 全名、别名、关系、背景关键事实（[{date} 来源]），用户确认的标注「用户确认」。

## 关系动态时间线（浓缩 + 指针）

- [{date}] 一句话事件 + 关系含义 → [[复盘-{date}]]

## 待确认或存疑

- 证据不足的判断集中在此，标注置信度，不写死。

## 相关雷区与注意

- 涉及此人的对话红线、敏感点或归因禁忌。
