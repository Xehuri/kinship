# 给使用者的入口

Kinship（知己）是一套自托管的健康与行为监测系统：手机和 Windows 电脑采集数据，后端负责存储，Loom 助手负责分析并给出提醒和复盘。它不依赖云厂商账号，数据留在自己的机器上。

## 第一次使用

1. 由部署者完成安装，见 [安装手册](../ops/INSTALL.md)。
2. 打开浏览器访问部署地址，按页面提示创建管理员账号。
3. 在手机安装 Android App，按引导连接服务器并授权传感器。
4. 需要 PC 状态采集时，安装 Windows 桌面端，见 [桌面端说明](../../desktop/README.md)。

## 可选功能怎么开

MOSS 深度音频、小米健康云、QQ 网关、唤醒词和 PC 采集器的开关方式集中在 [可选功能](features.md)。这些功能默认关闭，不影响基础健康数据采集。

## 遇到问题

- 不知道配置改哪里：看 [配置参考](../ops/CONFIGURATION.md)。
- 想确认某个数据字段：看 [数据格式](../dev/DATA_FORMAT.md)。
- 文档不知道从哪找：看 [真源矩阵](../README.md)。
