# 可选功能怎么开

基础健康数据采集不需要打开这些功能。下面按“它做什么、在哪里开、前提是什么”说明。写配置键时以项目根 `config.yaml` 为准，改完按 [配置热更新](../ops/system-config-hot-reload.md) 应用。

## MOSS 深度音频

MOSS 是旁路音频理解服务，对已经落盘的音频 chunk 做场景、静音和环境音分析，结果写入 `audio_deepdive.jsonl`，不修改 `perception.jsonl`，也不影响主分析链。

在哪里开：

1. 首次引导的 `moss` 步骤可以直接填写 MOSS 服务地址并启用。
2. 已经在用的实例，把 `moss.enabled` 设为 `true`，并确认 `moss.base_url` 指向 MOSS vLLM 服务，默认 `http://127.0.0.1:8100`。

前提：单独部署 `axeuh-moss` 推理服务；没有 GPU 或没有该服务时保持关闭。转正门与观察口径属于私有运维文档，公开树不提供链接。

## 小米健康云

把小米运动健康云端的心率、步数、血氧、压力、卡路里、静息心率和睡眠按水位增量拉到本机。

在哪里开：首次引导的 `xiaomi` 步骤扫码登录；也可以在 Web UI 设置中手工配置。

前提：有一个能登录小米运动健康的账号。不接它时，手机 App 直传照常工作。

## QQ 网关

把 QQ 私聊和群聊接进 Loom 助手，使用单 WebSocket 加 SQLite 收件箱，`qq` CLI 通过本机 `127.0.0.1:8770` 发送消息。

在哪里开：把 `qq_gateway.enabled` 设为 `true`，并按 [QQ 网关契约](../dev/qq-gateway.md) 配置 NapCat 地址和账号。默认关闭。

## 唤醒词

环境音频里听到唤醒词时触发一次语音交互。默认唤醒词是“小贺同学”。

在哪里开：在设置页的语音相关分组里启用，或在 `config.yaml` 的唤醒词配置节填写。需要手机端麦克风权限。

## PC 状态采集

采集 Windows 电脑的前台窗口、空闲和锁屏状态，上报到 `/api/pc/sync`。

在哪里开：安装 Windows 桌面端，桌面端会内置并托管 PC 采集器；服务器地址和证书在桌面端首次运行时配置。见 [桌面端说明](../../desktop/README.md)。
